# Codigo_QR
Generador de código QR construido desde cero en Python.

## Descripción
El objetivo es generar un código QR **versión 2 (matriz de 25 × 25 módulos)** implementando cada etapa: 
la conversión del texto a ASCII, el armado de la cadena de bits, la
construcción de la matriz y la colocación de los patrones.

## Requisitos

Python 3. No requiere instalar nada.

## Ejecución

```bash
python codigo_qr.py
```
